# MacroSnap 🍽️

MacroSnap is an AI-powered nutrition assistant that analyzes food and provides estimated nutritional information such as calories, protein, carbohydrates, and fat.

## 🚀 Features

- 📸 Analyze meal/food images
- 📝 Analyze food descriptions
- 🤖 AI-powered nutrition analysis using Google Gemini
- 📊 Provides estimated calories and macronutrients
- 💬 WhatsApp integration using Twilio
- 🌐 Streamlit web application

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Twilio
- WhatsApp
- Pandas
- NumPy

## 📋 Requirements

- Python 3.12 or later
- Google Gemini API key
- Twilio account
- Internet connection
